# YPF Ikola — Community Website

This version is a fuller rebuild of the supplied YPF Ikola site.

## Included
- Public home/community site
- Come → Connect → Grow → Serve journey
- Small Cells and four district clusters
- Peer Groups
- Events section
- WhatsApp community link
- Giving section with the supplied Pocketapp transfer details
- Supabase sign-up/login
- Member area
- Admin member management

## Important
The site still uses the existing Supabase project/configuration. Database security (especially Row Level Security policies) must be checked in Supabase before production use.

The public photography currently uses remote Unsplash image URLs, so an internet connection is required for those images. Replace them with YPF-owned photographs when available.

## Deploy
Upload the contents to your hosting provider (e.g. Vercel). The site is plain HTML/CSS/JS and does not require a build command.
